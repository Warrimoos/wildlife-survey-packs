# Security policy

## Reporting a problem

If you find a security or privacy problem in African Wildlife Survey, Warrimoo Wildlife, or the files and web pages in this repository, please email **apps@warrimoo.net** with "Security" in the subject line, or use "Report a vulnerability" on this repository's Security tab if it is shown. Please do not open a public issue for a security problem.

Tell us what you found, how to reproduce it, and which version of the app or file you used. You will get a reply within 7 days. If the report is confirmed, a fix will go out in the next release and you will be credited if you wish.

## In scope

- The pack files (zips) and web pages in this repository.
- The African Wildlife Survey and Warrimoo Wildlife apps for Android.

## Out of scope

- Problems that need a rooted phone or physical access to an unlocked phone.
- The third party services the apps link to, such as iNaturalist, xeno-canto, Google Maps and GitHub.

## Supported versions

Only the latest release of each app and the current pack files are supported. The apps keep all records on the device and have no accounts or servers of their own.
